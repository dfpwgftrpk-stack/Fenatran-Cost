    Sobre o app

    Fenatran Cost Engineering

    Aplicativo da equipe Mercedes-Benz para registrar ideias e referências vistas na Fenatran: marca, modelo, Leg, comentários e fotos.

    Todos os registros ficam numa galeria compartilhada. Marque com estrela os que você quer rever e acompanhe os números no Dashboard.

    Seus registros ficam salvos neste aparelho. Para entregar suas ideias à equipe, use "Enviar meus registros" no menu Mais. O nome de quem registrou não aparece na galeria nem nos detalhes.

    Logo oficial

    O app já usa o logo enviado. Para trocar, insira outro arquivo (PNG ou SVG). Ele aparece nas barras de título e no menu Mais. Remover volta para o logo original.

    Imagem da capa

    A capa já usa a imagem do estande. Para trocar, insira outra imagem vertical (proporção 9:16). Remover volta para a imagem original.

    Compartilhar app

    Aponte a câmera do celular para o QR Code para abrir o Fenatran Cost Engineering.

    Cole aqui o endereço onde o arquivo do app está publicado. O QR Code e os botões usam este endereço.
    Compartilhar no WhatsApp Enviar por e-mail

    Se o link não abrir para alguém, confirme com o responsável se o arquivo do app está publicado em um endereço que todos acessam.

    Administrador

    Área restrita a pessoas autorizadas. Digite o código de administrador para abrir a exportação de dados.

    Receber ideias automaticamente

    Cole o endereço do receptor e o código de segurança. Depois disso, cada ideia salva é enviada sozinha, com fotos. Use "Compartilhar app" para distribuir um link que já vem configurado.

    O código de administrador é conferido pelo Google e não fica salvo neste aparelho.
